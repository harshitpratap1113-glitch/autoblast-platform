## 🌟 Overview

**AutoBlast AI** is an omnichannel social broadcasting engine built for SaaS founders, content creators, and growth hackers. From a single product link or campaign prompt, AutoBlast AI automatically synthesizes platform-tailored viral copy for **WhatsApp, Telegram, Discord, Reddit, Twitter/X, and Instagram**, and dispatches campaigns with built-in **Anti-Ban Jitter & Rate-Limiting Protection**.

---

## ✨ Key Features

- 🧠 **AI Multi-Channel Content Multiplier**: Generates 6 platform-tailored variations (emojis, markdown, hashtags, tailored CTAs).
- 🛡️ **Anti-Ban Jitter Engine**: Employs human variance delays (1.2s - 2.8s) and rotating payload headers to prevent spam flags.
- 🔌 **Universal Connectors**: Native support for:
  - **Telegram Bot API**
  - **Discord Webhooks & Bot Gateways**
  - **Reddit Subreddit Post API**
  - **Twitter/X v2 API**
  - **WhatsApp Baileys & Webhook bridges**
- 📊 **Real-Time Click Tracking**: Deep-linked redirect engine (`/t/{tracking_id}`) recording real impressions, click-through rates, and conversion analytics.
- 🎨 **Dark-Neon SaaS Dashboard**: Fast, responsive, glassmorphic UI with 1-click test dispatches.

---

## 🛠️ Architecture & Tech Stack

- **Frontend**: Clean Modern JavaScript (ES6+), Semantic HTML5, Dark-Neon TailwindCSS palette.
- **Backend**: Python FastAPI & Node.js dispatcher microservices.
- **Hosting & Infrastructure**: Vercel Edge Serverless Platform.
- **Telemetry**: Real-time traffic analytics via [TrafficPulse AI](https://trafficpulse-platform.vercel.app).

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/harshitpratap1113-glitch/autoblast-platform.git
cd autoblast-platform
```

### 2. Run locally
```bash
# Using Python FastAPI (if backend is present)
pip install -r requirements.txt
python main.py

# Or using local static server
npx serve .
```

Open `http://localhost:8001` or `http://localhost:3000` in your web browser.
