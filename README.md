# 🚀 AutoBlast AI - Omnichannel Viral Marketing & Broadcaster SaaS Engine

## 🌟 Overview
**AutoBlast AI** is a 100% automated viral marketing and multi-channel campaign broadcaster for SaaS founders, video editors, YouTubers, and digital creators.

It allows you to enter a single product link or campaign prompt, automatically generates tailored viral copy for **WhatsApp, Telegram, Discord, Reddit, Twitter/X, and Instagram Reels**, and dispatches the message across all connected channels in 1-Click with **Anti-Ban Jitter & Rate-Limiting Protection**.

---

## ⚡ Key Features
1. 🧠 **AI Multi-Channel Content Multiplier**: Generates 6 platform-tailored variations (emojis, markdown, hashtags, CTAs).
2. 🛡️ **Anti-Ban Jitter Engine**: Human variance delay (1.2s - 2.8s) preventing spam flags.
3. 🔌 **Universal Connectors**: WhatsApp Web / Baileys, Telegram Bot API, Discord Webhooks, Reddit OAuth, Twitter v2, Instagram Meta Graph.
4. 📊 **Real-Time Click Tracking**: Deep-linked redirect engine (`/t/{tracking_id}`) recording clicks, reach, and conversion analytics.
5. 🎨 **Dark-Neon SaaS Dashboard**: Fast, sleek, responsive, zero-clutter UI.

